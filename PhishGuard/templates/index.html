          Detection Engine Parameters

          PhishGuard uses a weighted heuristic engine. A total score of 30+ is Suspicious, and 60+ is Phishing.

          URL Architecture

          • IP Address as Domain

            URLs that use an IP address instead of a domain name (e.g., http://192.168.1.1) are highly suspicious as legitimate sites rarely use IPs.

            +30 pts
          • Contains @ Symbol

            The @ symbol can be used to hide the actual domain (e.g., google.com@phishing.com). Browsers ignore everything before the @.

            +15 pts
          • Excessive Subdomains

            Having 3 or more subdomains is a common tactic to bypass filters or create long, deceptive URLs (e.g., login.update.security.paypal.com).

            +15 pts
          • URL Shortener Used

            Services like bit.ly hide the final destination, frequently used by attackers to mask phishing URLs.

            +10 pts
          • Hyphenated Domain Correlation

            Detects multiple hyphens, or a single hyphen correlated with a young domain age (< 90 days), which is often used in brand spoofing.

            +10 pts
          • Semantic Keywords

            Detects credential-harvesting keywords like 'login', 'secure', or 'update'.

            +10 pts per word
          • Excessive URL Length

            URLs longer than 75 characters are slightly suspicious, as attackers use long URLs to hide the actual domain from view.

            +5 pts
          • Suspicious Tunneling Service / Temporary Hosting

            Services like Cloudflare Tunnels or Ngrok provide instant, disposable HTTPS URLs heavily abused by phishing kits. Known temporary hosting services add suspicion.

            +15 pts
          • Random / Generated Subdomain

            Detects high-entropy subdomains, randomly generated strings, or excessive numbers often used by threat actors to evade blocklists.

            +10 pts

          Domain & Reputation

          • Flagged by Safe Browsing / PhishTank / VirusTotal / URLhaus

            If the URL exists in any of these external threat intelligence databases, it is immediately classified as phishing.

            +100 pts
          • Domain Age < 7, < 30, < 90 Days

            Most phishing domains are active for a very short period. Newly registered domains carry high risk based on their exact age.

            +25, +15, +10 pts
          • Invalid/Missing SSL

            Websites asking for credentials without HTTPS, or with invalid SSL certificates, are insecure and suspicious.

            +25 pts
          • WHOIS Info Hidden/Missing

            Attackers frequently hide domain registration details or use registrars that don't publish WHOIS data.

            +15 pts

          Content Integrity

          • Password Field on HTTP

            Any webpage containing a password input field must use HTTPS. Lack thereof is a critical vulnerability.

            +35 pts
          • Form Submits to External Domain

            Phishing sites often host a fake login page on one domain, but the `

            ` sends stolen credentials to an entirely different server.

            +30 pts
          • Hidden iFrames Detected

            Invisible iFrames (width: 0, height: 0, or display: none) are used to silently load malicious payloads or track users.

            +20 pts
          • Right-Click Blocked

            Attackers disable right-click or inspection tools to prevent security analysts from easily viewing the source code of the phishing page.

            +15 pts
          • Page Content Unreachable

            If the scanner is blocked (e.g. by anti-bot measures) or times out, the page is considered somewhat suspicious.

            +15 pts
          • Favicon Domain Mismatch

            A legitimate site usually hosts its own favicon. Phishing sites sometimes load the favicon directly from the targeted legitimate brand's external server.

            +10 pts
