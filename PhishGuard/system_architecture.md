# PhishGuard System Architecture & Operation Manual

## 1. Overview
PhishGuard is a real-time, heuristic-based phishing detection engine. Instead of relying solely on static blocklists, the system actively analyzes a URL across three distinct vectors: **URL Architecture**, **Domain & Reputation**, and **Content Integrity**. It uses a weighted scoring engine to evaluate the likelihood that a provided URL is attempting a phishing attack.

---

## 2. System Workflow
1. **User Input:** A URL is submitted via the UI dashboard.
2. **Preprocessing:** The backend API ensures the URL is properly formatted and includes a valid scheme (e.g., prepends `http://` if missing).
3. **Parallel Analysis:** The system invokes four specialized analyzer modules simultaneously.
4. **Score Aggregation:** The `calculate_score` engine aggregates the results, applying weighted risk points to triggered heuristic rules.
5. **Verdict Generation:** The final score determines the classification (SAFE, SUSPICIOUS, or PHISHING).
6. **Explainable Output:** The backend returns a detailed JSON object outlining exactly *why* the URL received its score, which is rendered dynamically on the frontend.

---

## 3. Analyzer Modules & Heuristics

### 3.1. URL Analyzer (`rules/url_analyzer.py`)
This module evaluates the structural composition of the URL itself.
- **IP Address as Domain (+30 pts):** Legitimate sites use domains. IPs often indicate evasion tactics.
- **Excessive Length (+5 pts):** URLs over 75 characters.
- **At-Symbol `x@y.com` (+15 pts):** Used to spoof the visual domain in a browser.
- **URL Shorteners (+10 pts):** Masks the true destination (e.g., bit.ly, tinyurl).
- **Excessive Subdomains (+15 pts):** Three or more subdomains (e.g., `login.secure.update.paypal.com`).
- **Hyphenated Domain (+10 pts):** Multiple hyphens are a hallmark of spoofed brand domains.
- **Suspicious Tunneling/Temporary Host (+15 pts):** Detects usage of free tunneling providers like Cloudflare Tunnels (`trycloudflare.com`) and Ngrok, which are heavily abused for disposable infrastructure.
- **Random/Generated Subdomain (+10 pts):** Employs regex to detect high-entropy strings, long numeric sequences, or heavily hyphenated subdomains.

### 3.2. Domain Analyzer (`rules/domain_analyzer.py`)
This module queries external WHOIS/RDAP databases and performs connection tests.
- **Domain Age:** Extracts the exact creation date of the registered domain.
  - `< 7 days old` = +25 pts
  - `< 30 days old` = +15 pts
  - `< 90 days old` = +10 pts
- **WHOIS Anomalies (+15 pts):** Missing critical registration data (registrar, dates).
- **SSL Issues (+25 pts):** Non-HTTPS traffic or invalid SSL certificates on the target site.

### 3.3. Content Analyzer (`rules/content_analyzer.py`)
This module scrapes and parses the HTML of the target page.
- **Insecure Login Form (+35 pts):** `type="password"` input found on a non-HTTPS page.
- **External Form Target (+30 pts):** A `<form action="...">` that sends credentials to a completely different domain than the one hosting the page.
- **Hidden iFrames (+20 pts):** Invisible frames used to silently drop payloads or track users.
- **Right-Click Blocked (+15 pts):** Disabling context menus to prevent security analysis.
- **Content Unreachable (+15 pts):** The server refused the connection or timed out (often a sign of anti-bot measures used by phishing kits).
- **Mismatched Favicon (+10 pts):** The favicon is hosted on an external (often targeted) brand's domain.

### 3.4. API Intelligence (`rules/api_analyzer.py`)
Queries established threat intelligence feeds.
- **Google Safe Browsing (+100 pts)**
- **PhishTank (+100 pts)**
- **VirusTotal (+100 pts)**
- **URLhaus (+100 pts)**
*Note: Any trigger here results in an immediate PHISHING verdict, as the score caps at 100.*

---

## 4. Scoring Engine (`engine/scoring.py`)
The scoring engine acts as the central brain. It takes the detailed outputs from all analyzers and aggregates the points.

**Verdict Thresholds:**
- **0 – 29 Points:** SAFE (`Legitimate`)
- **30 – 59 Points:** SUSPICIOUS
- **60 – 100 Points:** PHISHING

The final score is hard-capped at 100. The engine also categorizes the score into *URL Architecture*, *Domain & Reputation*, and *Content Integrity* to drive the visual telemetry charts in the UI.

---

## 5. UI & Explainability
PhishGuard is built with a focus on explainability. Instead of a black-box result, the frontend (`index.html` & `script.js`) parses the `reasons` and `technical_details` generated by the engine. 

When a scan is complete, the UI populates:
1. **Threat Telemetry Breakdown:** A Polar Area chart showing risk distribution.
2. **Detection Reasons:** Human-readable explanations for triggered rules (e.g., "Temporary tunnel hosting detected: Cloudflare Quick Tunnel").
3. **Technical Details:** Exact metrics such as the parsed registered domain name and precise domain age in days.
